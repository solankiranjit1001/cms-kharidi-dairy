# CMS ખરીદી ડાયરી — પ્રોટોટાઇપ

આ Gujarati mobile-first PWA નો પ્રથમ પ્રોટોટાઇપ છે.

## હાલમાં શું કામ કરે છે?
- ગુજરાતી મોબાઇલ ડેશબોર્ડ અને મોટા બટન
- બજાર ભાવ/આવક નોંધ
- ખરીદી અને વેચાણ નોંધ તથા રકમની ગણતરી
- સ્ટોક/બગાડ/ખર્ચ નોંધ
- નોંધાયેલ ભાવ પરથી સરળ ઇતિહાસ સારાંશ
- સપોર્ટેડ બ્રાઉઝરમાં વૈકલ્પિક ગુજરાતી વૉઇસ નોંધ
- JSON બેકઅપ અને ઇમ્પોર્ટ
- HTTPS હોસ્ટિંગ પર હોમ સ્ક્રીનમાં ઉમેરવા અને મર્યાદિત ઑફલાઇન ઍક્સેસ માટે PWA માળખું

## મહત્વની મર્યાદાઓ
- આ હજી પ્રોટોટાઇપ છે, સંપૂર્ણ પ્રોડક્શન એપ નથી.
- નોંધો હાલના ફોન/બ્રાઉઝરના local storage માં જ રહે છે. આપમેળે બીજા પરિવારના ફોન સાથે sync થતી નથી.
- ગુજરાતી speech recognition દરેક ફોન/બ્રાઉઝરમાં ઉપલબ્ધ કે ચોક્કસ નથી; ઘણી વાર ઇન્ટરનેટ જોઈએ. સાચવતાં પહેલાં ઓળખાયેલી વિગતો તપાસવી.
- આવતીકાલની યોજના માત્ર નોંધાયેલ ભાવનો સારાંશ છે; આગાહી કે નફાની ખાતરી નથી.
- production પહેલાં login, cloud database, સુરક્ષિત sync, unit tests, restore flow, અને બજારની વાસ્તવિક નોંધો વડે પરીક્ષણ જરૂરી છે.

## ચલાવવાની રીત
1. આ ફોલ્ડરની ફાઇલો HTTPS static hosting પર મૂકો (ઉદાહરણ: GitHub Pages અથવા Netlify).
2. HTTPS URL મોબાઇલ Chrome માં ખોલો.
3. Chrome મેનૂમાંથી “Add to Home screen” અથવા “Install app” પસંદ કરો.
4. માઇક્રોફોન માટે પૂછાય ત્યારે પરવાનગી આપો. HTTPS જરૂરી છે.
5. પરિવારના અનેક ફોન માટે આગળના તબક્કામાં shared database/authentication ઉમેરવું પડશે.

## આગળનો વિકાસ
1. Supabase/Firebase જેવી cloud database અને authentication.
2. પરિવારના દરેક સભ્ય માટે login અને records sync.
3. દર શાક માટે સ્ટોક ગણતરી: opening + purchase - sale - wastage = closing.
4. વર્ષવાર અને સીઝનલ સરખામણી, સમાન તારીખની આસપાસના સમયગાળાનો ઇતિહાસ.
5. ખરીદીની ભલામણ માટે ભાવ સાથે આવક, સ્ટોક, માંગ, વેચાણની ઝડપ અને વિશ્વાસ સ્તરનો સમાવેશ.
