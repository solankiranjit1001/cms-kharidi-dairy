# CMS ખરીદી ડાયરી — આવૃત્તિ 6 (સાદો દૈનિક હિસાબ)

ભાવનગરના શાકભાજી જથ્થાબંધ વ્યવસાય માટે ગુજરાતી, મોબાઇલ-પ્રથમ હિસાબ એપ. પરિવારના બધા સભ્યો પોતાના ફોનથી
લોગિન કરે છે અને એક જ સુરક્ષિત ડેટાબેઝ (Neon PostgreSQL) વાપરે છે.

## મુખ્ય સુવિધાઓ
* મોબાઇલ નંબર + PIN લોગિન; ભૂમિકા: માલિક / એન્ટ્રી / ફક્ત જોવું
* એક બિલમાં અનેક શાકની ખરીદી, આંશિક ચુકવણી (બાકી વેપારી ખાતામાં), ટ્રાન્સપોર્ટ ખર્ચ
* દિવસના અંતે **એક જ રકમ** — ગ્રાહકો પાસેથી મળેલ કુલ વેચાણ (શાક પ્રમાણે વેચાણ કે સ્ટોક લખવાની જરૂર નથી)
* હોમ પર: આજની ખરીદી, વેચાણ, વેપારીને ચૂકવેલ, ચૂકવવાના બાકી, ખર્ચ અને **આજનું પરિણામ (+/−)**
* વેપારી ખાતાવહી (શરૂઆત, ખરીદી, પરત, ચુકવણી, સુધારો) — મહિનાના અંતે ચુકવણી ચાલે
* ફેરફાર કારણ સાથે, રદ (કાયમી delete નહીં), દરેક ફેરફારનો ઇતિહાસ
* ગુજરાત બજાર ભાવ સર્વે, બજાર/મહિના/ઋતુ પ્રમાણે સરખામણી
* ગુજરાતી રિપોર્ટ, A4 આડું દૈનિક ડાયરી પ્રિન્ટ
* જૂની એપનો ડેટા સુરક્ષિત ઇમ્પોર્ટ
